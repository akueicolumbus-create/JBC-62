# South Sudan Connectivity Reality

A Streamlit dashboard comparing mobile and Starlink pricing, household device access, and an illustrative tax burden.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Sign in at [share.streamlit.io](https://share.streamlit.io/) with GitHub and authorize access to this repository.
2. Select **Create app**, choose `akueicolumbus-create/JBC-62`, the `main` branch, and `app.py` as the entry point.
3. Select **Deploy**. Streamlit Cloud installs dependencies from `requirements.txt`.
